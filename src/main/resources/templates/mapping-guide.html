Important: Mobile Number Distinction
  • Payer's Mobile (Contact) → /Dbtr/CtctDtls/MobNb - From Tag 62/09 'M' (Prompted Consumer Data)
  • Merchant Mobile (Top-up) → /UltmtCdtr/Id/PrvtId/Othr/Id with scheme MOBN - From Tag 62/02
