QR to ISO 20022 (pacs.008) Mapping Guide

This guide shows how Ethswitch QR tags, user-prompted inputs, and system defaults are mapped to the final ISO 20022 payment message.

Mapping Priority: The system follows a strict priority for field values: 1. User Input (Prompted) 2. QR Tag Data 3. System Defaults
